## 容器掃描仍待處理，不能宣稱零漏洞

npm audit 不包含所有系統套件與 Caddy 內建 Go 依賴。本輪另用官方 Trivy 掃描兩個驗收映像，結果保存在上述 evidence JSON，沒有加入忽略規則掩蓋告警。

- 更新 npm 後，後端映像的 Node 套件 High／Critical 比對紀錄為 0；Debian 12.15 基底仍有 35 筆套件比對紀錄（34 High、1 Critical，合計 11 個不同 CVE），掃描未提供該發行版的修補版本。**這不是已證明本站有 35 個可利用漏洞。** 下次須逐項評估可達性、參照 Debian 狀態，或評估新版基底後重跑測試。
- Critical 的 CVE-2023-45853 屬 MiniZip；[Debian 官方追蹤](https://security-tracker.debian.org/tracker/CVE-2023-45853)註明 Bookworm 的 src:zlib 未建置該 contrib/minizip，因此不能單憑套件命中判定實際二進位受影響。尚未將這項資訊寫成自動忽略規則。
- 前端 Alpine 系統套件 High／Critical 為 0；Caddy 二進位仍有 go-jose/v3 與 x/net 兩項 High 比對。後者有上游修補版本，前者的舊主版本沒有掃描可辨識修補版。下次檢查更新後的官方 Caddy 映像、實際模組可達性及必要修補，不直接將掃描結果當成可利用性結論。
- [go-jose 官方公告](https://github.com/go-jose/go-jose/security/advisories/GHSA-mgcc-cww5-fp2q)涉及不受信任 JWK 的 RSA 解析；[Go 官方公告](https://pkg.go.dev/vuln/GO-2026-6860)涉及 HTML 解析。本專案目前的 Caddy 設定以靜態檔案與反向代理為主，**尚未完成二進位呼叫路徑的證明**。

上線前須留下修補或適用性判定，並記錄正式映像摘要。本輪沒有完成第三方滲透測試或完整壓力測試。

5. 備份／還原仍依維運手冊，在**專用 project** 設 `CMS_BACKUP_PROJECT`、`CMS_RESTORE_PROJECT` 與 `CMS_COMPOSE_OVERRIDE`；restore 會覆寫目標，禁止指向既有服務。
