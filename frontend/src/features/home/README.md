# 首頁模組

> 活動相關區塊現由共用公開快照供應，預設 API，另有明確選用的 JSON 靜態模式；輪播與其他首頁內容仍維持原來源。下文 JSON 路徑為原始內容基準。API 模式更新公開資料後，下次重新讀取會同步更新最新消息、日曆、ICS、導覽與搜尋，不需重建前台。

- `HomePage.tsx`：組合首頁區塊，管理單一活動視窗。
- `components/`：焦點輪播、近期活動、快捷選單、行事曆、Google 日曆匯入。
- `data/home.ts`：首頁輪播資料，以及從共用已發布活動衍生的月曆活動清單。
- `homeTypes.ts`：首頁資料型別。
- `utils/calendarExport.ts`：ICS 下載及 Google 日曆連結。
- `home.css`：首頁區塊樣式，匯入視窗另使用 CSS Module。

全站搜尋由 `src/shared/data/search.ts` 匯整，快捷選單由 `src/shared/data/navigation.ts` 產生，首頁不再複製部門、隊伍或學習資源資料。
最新消息使用共用的已發布活動 JSON，只讀取有開始日期的活動，以台灣日期篩選尚未結束的活動（含進行中），按開始日期、ID 排序取三筆。`date` 是開始日期，選填的 `endDate` 是最後一天，包含當天；省略結束日期即為單日活動。一般卡片顯示照片、完整日期區間與活動分類，其他活動顯示實際活動名稱；有 `album` 時使用相簿封面並保留圖片 fit。無日期活動仍能瀏覽介紹；填入實際日期後重新建置部署，即自動參與最新消息排序。活動詳細頁及其他活動相簿也會顯示已設定的日期區間；已知地點供資訊彈窗、行事曆及匯出使用。
首頁與系隊輪播共用 `src/shared/hooks/useCarousel.ts`。

行事曆與系上活動共用 `src/content/activities/events/*.json`，只顯示已發布且有開始日期的活動，從開始到結束的每一天都顯示，支援跨月、跨年；包含過去活動以供切換月份瀏覽，同日依開始日期、ID 排序。有詳細內容時直接連到活動頁，否則開啟活動資訊視窗。今天與預設月份依 `Asia/Taipei` 判定，圖例沿用活動分類；手機保留活動名稱並允許換行。資訊視窗的 Google 單筆新增與 ICS 批次匯入共用同一清單，包含介紹、已知地點及活動網址；ICS 使用活動 ID 作為穩定 UID。每個活動匯出為一筆涵蓋完整區間的全天活動，格式中的結束日期為最後一天的隔天（不包含）；匯入 Google 後不會自動同步。無日期項目需填寫日期並重新建置部署才會出現在日曆。
首頁頂部主視覺每 4.8 秒換句，滑鼠停留時持續播放，鍵盤焦點進入時暫停換句；打字使用逐字 CSS 顯示，並預留所有句子的空間以避免手機換句時版面跳動。三條波浪由各自的 HTML 層執行位移。主視覺離開畫面或分頁隱藏時暫停動畫及換句，恢復後重新計時；減少動態效果設定會停止自動換句並直接顯示全文。
共用輪播的第三個參數可設定 `pauseOnHover`（預設 `true`）與 `autoplayEnabled`（預設 `true`），其他輪播維持原本行為。
