# H-1／I-7／K：待執行驗收清單

本文件為可重跑流程及記錄格式，2026/11/10 僅撰寫，依「不要驗證」尚未執行。本次沒有建置、Prisma generate、migration、HTTP／瀏覽器、備份還原或告警探測。

## 自動化入口

取得驗證許可後，以獨立 PostgreSQL 容器建立專用測試庫並套用 migration，從 backend 目錄執行對應測試。測試會刪除隔離庫中的合成資料，禁止指向站台資料庫。資料庫名稱護欄不代表自動建立隔離環境；操作者需確認 URL、主機、project 與 volumes。

| 環境變數／資料庫名 | 測試檔 | 目前新增覆蓋 |
|---|---|---|
| `ACCOUNT_TEST_DATABASE_URL`／`account_test` | `accounts.test.ts` | 帳號／啟用／重設／Token／CSRF／角色／Session／最後管理員／Google callback 拒絕 |
| `WORKFLOW_TEST_DATABASE_URL`／`workflow_test` | `workflows.test.ts` | 活動權限／目的分類／草稿隔離／版本衝突／凍結／審核發布／下架還原、14 份組織授權／排序／版本／撤權、三組 K 工作流、首頁圖片引用／發布／緊急撤回 |
| 不需資料庫 | `site-content.test.ts` | 舊資料、首頁 URL／圖片／唯一識別值、設定 URL／社群／信箱、共用資源驗證 |

`node --import tsx --test test/workflows.test.ts` 為單獨入口，需先產生對應 Prisma Client。既有 `npm test` 仍先建置，並包含其他測試與有設定的隔離庫；沒有設定的資料庫測試會明確跳過，不能把跳過當作通過。既有聯絡／模型／公開內容／安全測試入口見 README。

新增測試未涵蓋所有負向與競態矩陣。仍須補實際 Google provider、多人同時寫入／發布、跨版本歷史分類過濾、全部媒體異常及容量／槽位、組織子項移除與側欄引用、已公開圖快取與前端各錯誤情境。單一版本過期案例不能代表已完成併發驗收。

## 真實瀏覽器流程（H-1c）

先在隔離測試站建立 ADMIN、只授權分類 A／部門 A／系隊 A 的 EDITOR、不同授權的另一位 EDITOR。使用真實 API 與資料庫，禁止 mock。合成資料與圖片須能辨認且不含個資。

- [ ] 帳密登入、登出、啟用、重設、停用與 Google 綁定／登入／拒絕；重放票券及舊 Session 被拒。
- [ ] 活動編輯 → 上傳 → 選圖 → 前台共用版型預覽 → 儲存 → 送審 → ADMIN 檢視同一凍結版本 → 發布 → 公開頁／近期活動／行事曆／ICS／分類導覽／搜尋更新。
- [ ] 部門與系隊對 4／9 份來源抽樣各種子頁，總覽 ADMIN 排序與發布；空合照、缺圖、空活動／聯絡與待填維持原意。子項移除不得留下側欄失效引用。
- [ ] 首頁輪播排序、替代文字、文案與連結；資源分類／頁面／流程／清單；全站設定一次發布後同步頁尾、聯絡頁、系學會與搜尋。
- [ ] 草稿不影響公開內容，私有圖片匿名不可讀；已發布再修改仍保留舊公開內容。下架只移除對應公開單位，其他頁面可使用。歷史還原產生草稿並再次審核。
- [ ] 直接進入未授權路由與 API、跨部門／隊伍／分類、撤權／停用後既有頁面操作；確認 401／403 與登入導引。
- [ ] 雙人編輯及過時 version 回 409、保留本地表單；送審後欄位凍結、退回原因、重複發布、送審期間修改與重試。
- [ ] 未儲存時內部導覽、返回／前進、重新整理與關閉分頁提示；讀取失敗重試、空資料、API 來源不回退舊 JSON、長請求／重複點擊。
- [ ] 桌機與手機的欄位、媒體庫、預覽、導覽、相簿與圖片裁切；鍵盤能到達、辨識 label、錯誤、狀態與焦點；輪播暫停／減少動態偏好維持。
- [ ] 電機營、電機週的舊網址／分頁、其他活動相簿、跨日與台灣日期、同日多活動、ICS 全日區間、搜尋不索引草稿。
- [ ] 聯絡收件合成資料的提交、永久儲存、未讀數、篩選、分頁、詳情、重複標記已讀、ADMIN 限制及限速。

## 正式環境／維運

- [ ] 正式 HTTPS、Secure／HttpOnly／SameSite Cookie、同源 CSRF、代理 IP 辨識、前台／API 安全標頭及 OAuth callback；完整 CSP 先維持 Report-Only。
